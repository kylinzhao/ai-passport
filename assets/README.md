# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

## Images

Store reusable source images and generated display assets in `images/`.

| File | Dimensions and format | Use and source |
| --- | --- | --- |
| [`images/home.jpg`](images/home.jpg) | 3840 × 2160, JPEG | Product hero image embedded in both project README files to foreground AI Passport and its open, maker-oriented identity. |
| [`images/readme-hardware-specs.png`](images/readme-hardware-specs.png) | 2172 × 724, PNG RGBA | Optional technical infographic retained as a reference asset; it is no longer used as the homepage hero. Generated for this repository with the built-in image generation tool on 2026-09-17; the six labels and values were checked against the documented hardware contract. |
| [`images/logo-wordmark.png`](images/logo-wordmark.png) | 1648 × 336, PNG RGBA | Transparent black wordmark extracted from the repository's original `images/logo.png`; embedded in both project README files for light backgrounds. |
| [`images/logo-wordmark-dark.png`](images/logo-wordmark-dark.png) | 1648 × 336, PNG RGBA | White version of the extracted wordmark, used by the README `<picture>` element when GitHub is in dark mode. |

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

### zcode-pet device assets (generated by `scripts/gen_device_assets.sh`, do not edit by hand)

| File | Content and source |
| --- | --- |
| [`../main/assets/pet/`](../main/assets/pet) (12 `.zpf` files) | Animation frame packs baked offline by the desktop vector pet engine in the zcode-pet repository (`--export-esp32`); ZPF1 format: fixed 16-color RGB565 palette + 1bpp transparency-mask RLE + 4bpp indices, 118×76 @ 8 fps, device upsamples 2×; no hand-drawn art |
| [`../main/zcp_strings.c`](../main/zcp_strings.c) | Closed-set Chinese string table (sync mids + device mids and named symbols), generated from `zcode-pet/scripts/device_strings.txt` (both sections) |

| [`fonts/zcp_font_16.codepoints.txt`](fonts/zcp_font_16.codepoints.txt) | Registered codepoint set of `zcp_font_16.c` (registration baseline for the `build_pet.sh` coverage check: string codepoints ⊆ registration ∪ printable ASCII); regenerated together with the font by `scripts/gen_device_assets.sh` |

- Pet-canvas background constant: `#1A1A1A` (RGB565 `0x18C3`) — semi-transparent pixels are flattened onto it at bake time; the pet page background must use the same color (see `main/zcp_mirror.h` `ZCP_BG_HEX`).
- To add or change strings: edit `zcode-pet/scripts/device_strings.txt` and rerun `scripts/gen_device_assets.sh`; the charset whitelist and sync assertions live in the zcode-pet repository's `scripts/check_esp32_bridge.sh`.
- Regeneration requires: macOS `swiftc`, `lv_font_conv` (`npm install -g lv_font_conv`), and a CJK TTF via `FONT_TTF` (default `~/.zcode-pet/fonts/NotoSansCJKsc-Regular.otf`).
